Servidor LAMP

Despliegue de un entorno LAMP con Apache, PHP y MariaDB, acceso HTTPS y autenticación básica.

  • Apache
  • PHP
  • MariaDB
  • HTTPS
PROYECTO DE FORMACIÓN

El objetivo

Conectar la administración de sistemas con una aplicación web: servicio HTTP, ejecución de PHP y acceso a la base de datos.

01

Publicación con Apache

Configuración de VirtualHost, alias y permisos de directorios para servir el proyecto desde una ruta específica.

02

HTTPS y autenticación

Prácticas con TLS y certificados de laboratorio, autenticación básica y comprobación de respuestas HTTP con curl.

03

PHP y base de datos

Conexión PHP con MariaDB, formularios y consultas; diagnóstico de errores mediante registros de Apache y configuración de la conexión.

LO QUE ME LLEVO

Una página en blanco también se diagnostica. Revisar los registros y comprobar cada capa ayuda a encontrar la causa del error.
